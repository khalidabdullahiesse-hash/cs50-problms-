# CS50 Problems

A small collection of introductory C programming exercises completed while studying CS50 concepts.

## 🧩 Included exercises

| Exercise | Demonstrates |
|---|---|
| `cash.c` | Greedy coin counting with loops and conditionals |
| `mario-less` | A saved CS50 Mario exercise artifact |

## 🧰 Technology

- C
- CS50 library
- Command-line compilation and execution

## 🚀 Run the source exercise

With the CS50 library and toolchain installed:

```bash
clang cash.c -lcs50 -o cash
./cash
```

The program requests a positive change amount and prints the minimum number of US coins using 25, 10, 5, and 1-unit denominations.

## 🎯 Skills demonstrated

Input validation, loops, branching, counters, and greedy problem solving.
